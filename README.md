# scoop-socrates

A [Scoop](https://scoop.sh) bucket for [Socrates](https://nireus79.github.io/Socrates-ai/), a free beta chat with four artificial Greek philosophers. It runs on your computer and uses your own Claude or OpenAI key.

```
scoop bucket add socrates https://github.com/Nireus79/scoop-socrates
scoop install socrates
```

Needs the WebView2 runtime (part of Windows 11; install it first on Windows 10). The build is a beta and is not code-signed, so Windows may warn. The files come from the project's releases: https://github.com/Nireus79/Socrates-ai/releases

Source code and issues: https://github.com/Nireus79/Socrates-ai
